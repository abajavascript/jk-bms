File: None · No file · Rows written: 0

Start logging records into a file you choose. New file creates one when you enter a name. The file dialog defaults to tab-separated (.tsv). A name ending in .jsonl is JSON lines and starts with {"log":"jk-bms","version":1}; any other name is tab-separated. Existing file keeps its contents: an empty file starts a new log, and a file that already has this log's header for the same cell count can be appended or overridden. Stop logging ends the recording. Each finished row is saved before the next one. A dropped link reconnects and keeps using the same file. A reload forgets the chosen file; start again and pick the same file to append.
